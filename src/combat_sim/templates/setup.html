🛠️ Setup

Factions, units, weapons and points come from the community-maintained BSData wh40k-11e catalogues (not endorsed by Games Workshop). The app doesn't include them: download your own copy here, or point it at a folder of the .json files you already have.

Checking…

Download the latest catalogues

Fetches the newest version of every catalogue from GitHub into and uses it. If the download fails, the current data stays as it is.

Use a folder you already have

The folder holding Warhammer 40,000.json and the faction catalogues (for example a downloaded and unzipped copy of the GitHub repository).

Re-import

Changed the files in the folder yourself? Import them again (the app also notices on its next start).

Import notes

Things the importer couldn't read fully. The units still import; these are worth knowing when a result looks off.
