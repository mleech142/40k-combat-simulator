Setup

The app doesn't include any game data: download your own copy of each of the two data sets below. Neither is endorsed by Games Workshop. Download them again any time to update.

Download the game data

You need both: the first gives the units and points, the second the rules and stratagems that change the calculations.

1

Units, weapons and points

Every faction's datasheets, weapons, wargear and points from the community-maintained BSData wh40k-11e catalogues. Fetches the newest version from GitHub into and uses it; if the download fails, the current data stays as it is.

Rules and stratagems

Stratagems, detachment rules and army rules, word for word, from the Wahapedia data export (powered by Wahapedia). The app reads the effects it can model into modifiers; check or change them on the Data tab. Downloaded into ; they replace the app's own rules and stratagems of the same name.

Units: use a folder you already have

The folder holding Warhammer 40,000.json and the faction catalogues (for example a downloaded and unzipped copy of the GitHub repository).

Units: re-import

Changed the catalogue files in the folder yourself? Import them again (the app also notices on its next start).

Play (experimental)

Full games against a friend on a top-down board. Still being built: turn it on to try what's there so far.

Import notes

Things the importers couldn't read fully. The units and rules still import; these are worth knowing when a result looks off.
