## 40K Combat Simulator 2.2.3

### New

- **Share army lists as a code.** On the **Armies** page, **Share code** gives a short code for the open list; a friend pastes it into **Import code** to get the same list: faction, units, detachments, enhancements and wargear. It works between installs that have the same BSData files. Lists with custom units can't be shared, and anything the other install's data doesn't have is left out and named.

Download the zip for your system below, unzip it and run `40kCombatSimulator` (`.exe` on Windows). Your data carries over.
