## 40K Combat Simulator 2.0.0

**Unit data now comes from [BSData](https://github.com/BSData/wh40k-11e)**, the community-maintained catalogues behind BattleScribe and New Recruit: every faction, datasheet, weapon, wargear option and points cost for 11th edition, instead of the handful of units typed in from the spreadsheet. BSData is not endorsed by Games Workshop, and neither is this app.

### Getting started

1. Download the zip below, unzip it and run `40kCombatSimulator.exe` (Windows may warn about an unknown publisher: **More info → Run anyway**).
2. The app opens on its new **Setup** page. Click **Download latest** to fetch the catalogues from GitHub (a few seconds), or choose a folder of them you already have.
3. Continue to the Simulator.

The release doesn't include the catalogues: you download your own copy, and can update it any time from Setup. Units keep their identities across updates, so saved scenarios and comparisons keep working.

### New

- Every BSData faction and unit, with default loadouts, **wargear options** to swap in, and points for every legal unit size.
- **Detachments**: pick one per side in the Simulator and Analytics; rules and stratagems can be written for the whole faction or for one detachment. The Data tab shows BSData's army and detachment rule text to write them from.
- **Show Legends** toggles for unit searches.
- **Custom factions** for your own units, which can copy BSData weapons and stay linked to them.
- **Added modifiers** for BSData units (e.g. a Feel No Pain BSData doesn't spell out), kept across updates.
- Footer credit and data version on every page.

### Changed

- BSData units and weapons are read-only. Your own data (rules, stratagems, custom units, added modifiers) lives in the app data file.
- BSData has no stratagems or machine-readable rules: the core stratagems ship with the app; add your armies' rules and stratagems on the Data tab.

### Upgrading from 1.x

Version 1's data file and saved scenarios refer to units that no longer exist. On first start they are moved to `%APPDATA%\40K Combat Simulator\archive-v1\`, and you start with an empty scenario list.
