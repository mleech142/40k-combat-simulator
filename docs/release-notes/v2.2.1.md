## 40K Combat Simulator 2.2.1

### New: Linux

The app now comes for **Linux** as well as Windows. Download the zip for your system below.

**On Linux:** unzip it and run it from a terminal:

```bash
./40kCombatSimulator/40kCombatSimulator
```

Your browser opens the app; press Ctrl+C in the terminal to stop it. It needs a reasonably recent distribution (Ubuntu 22.04, Debian 12, Fedora 36 or newer). Your data lives in `~/.local/share/40K Combat Simulator/`. The [user guide](https://github.com/mleech142/40k-combat-simulator/blob/master/docs/user-guide.md) has the details.

**On Windows:** nothing changes from 2.2.0. Download the Windows zip, unzip it and run `40kCombatSimulator.exe`. Your data carries over.
